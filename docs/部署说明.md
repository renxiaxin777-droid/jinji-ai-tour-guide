# 晋迹 · 公网部署说明（Streamlit Community Cloud）

> 用途：满足大赛"联网功能须公网可达"的要求，评委可直接打开链接体验。
> 前置：本仓库已推送至 GitHub（renxiaxin777-droid/jinji-ai-tour-guide，private），本机代码为最新版。

## 一、部署步骤（约 5 分钟）

1. **登录** https://share.streamlit.io —— 用 GitHub 账号（renxiaxin777-droid）授权登录。
   - 首次使用需点 "Authorize streamlit" 允许其读取你的仓库（private 仓库需要此授权）。
2. 点 **Create app**（或 New app），选择 **Deploy a public app from GitHub**。
3. 填写：
   - Repository：`renxiaxin777-droid/jinji-ai-tour-guide`
   - Branch：`main`
   - Main file path：`app.py`
   - App URL：自定义子域名，建议 `jinji-guijian` 之类
4. 点 **Advanced settings → Secrets**，粘贴（把值换成真实 Key）：
   ```toml
   DEEPSEEK_API_KEY = "sk-你的DeepSeek密钥"
   ```
5. 点 **Deploy**，等待 2-5 分钟构建完成，得到形如
   `https://jinji-guijian.streamlit.app` 的公网链接。

## 二、部署后自检清单

- [ ] 落地页正常显示（古建大图 + 开始山西之旅按钮）
- [ ] 点击进入后侧边栏显示 **"DeepSeek 已连接"**（不是离线模式）

- [ ] 记录公网链接，填入提交材料

## 三、已知注意事项

| 项 | 说明 |
|---|---|
| 首次访问冷启动 | 免费实例空闲会休眠，首次打开需 20-60 秒唤醒，演示前建议先点开预热 |
| Python 版本 | 云端默认 3.11/3.12，代码兼容（本地为 3.14）；若构建报错可在 Advanced settings 指定版本 |
| 依赖 | `requirements.txt`（streamlit、edge-tts）已就绪；`requirements-lock.txt` 为本地精确版本备查 |
| 密钥安全 | Key 只放在云端 Secrets，**绝不**提交 `secret.py`（已在 .gitignore） |
| 资源限制 | 免费实例 1GB 内存；知识库为纯文本，占用极小 |
| 国内访问 | streamlit.app 在国内有时不稳定，演示时建议同时准备本地 `启动晋迹.bat` 兜底 |

## 四、备选部署方案（若 streamlit.app 不稳定或无法访问）

1. **Hugging Face Spaces**（免费，国内访问相对稳定）：新建 Space 选 Streamlit SDK，上传同一份代码，在 Settings → Repository secrets 配置 `DEEPSEEK_API_KEY`。
2. **本地 + 内网穿透**：`启动晋迹.bat` 起服务后，用 cpolar/frp/natapp 之类做临时公网映射（适合答辩当天临时用）。
3. **录制视频兜底**：演示视频本身即是"功能可运行"的证据，公网链接作为补充。

## 五、维护提示

- 代码更新后：运行 `python tools/push_via_api.py "update: 说明"` 推送（本机直连 github.com:443 不通，走 API 通道），Streamlit Cloud 会自动重新部署。
- 若 DeepSeek Key 更换：只需在 Streamlit Cloud 后台改 Secrets，无需改代码。
