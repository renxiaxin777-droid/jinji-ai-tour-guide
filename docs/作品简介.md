# 晋迹 · 山西古建智能导览体

面向山西古建文旅的工具调用型**大模型智能体**：不靠模型记忆随口作答，而是"先查资料、再开口"。

## 一、问题

山西古建筑约 2.8 万处、元及以前木构 509 处居全国之首。游客却有三难：**看不懂**（术语劝退）、**找不全**（精华散落县乡）、**不敢信 AI**（普通聊天机器人张口就报年代）。

## 二、方案

提问→DeepSeek 判断意图→调用工具（检索／详情／规划）→知识库返回带来源资料→讲解→语音播报。

自建知识库收录 **35 处重点古建、5 条精选路线**，覆盖四大区域，每条标注来源；未收录的明确回答"不知道"。与套壳机器人的差别：**每次工具调用的参数与返回资料，都在界面"智能体工作流"面板可视化**。

## 三、差异化功能

1. **四种导览模式**：小白／进阶／硬核／规划师，硬核档能讲清"佛光寺东大殿凭什么判定为唐构"。
2. **拍照识古建**：上传照片→识别形制→检索知识库→有据讲解；非古建照片会说明。
3. **断代路线**：按唐→五代→宋→辽→金→元编排，附形制特征。

## 四、技术

Python 3.14 + Streamlit 1.64.0；**DeepSeek（deepseek-chat）全程国产大模型**；语音 edge-tts；知识库为纯数据文件，新增景点零改代码；无密钥时可进离线演示模式。

## 五、价值

对游客，把"看不懂的建筑"变成"听得懂的故事"；对文旅行业，可复制的"垂直知识库＋智能体"范式。
