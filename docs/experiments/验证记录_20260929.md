## 一、修复项与验证结果

| # | 原问题 | 修复内容 | 验证方式 | 结果 |

## 二、真实 API 端到端冒烟（2026-09-29）

| 场景 | 输入 | 观察结果 |

| A 知识库命中 | 「应县木塔为什么千年不倒？」 | 调用 `get_attraction_detail`；回答含「据全国重点文物保护单位名录」✅ |
